# 05 · JavaScript: mảng, object, format, validate input

Dùng để **biến đổi** dữ liệu sau khi query và **kiểm tra** input trước khi query.
Lọc/sắp xếp/nhóm tập dữ liệu lớn thì làm trong query hoặc aggregate.
Mọi kết quả `→` bên dưới đã chạy thật trên Node 26 / Mongoose 9.

## Data mẫu (dùng cho mục 1-2)

```js
const books = [
  { title: 'Mat Biec',   price: 100, genre: 'Novel', stock: 5 },
  { title: 'Hoa Vang',   price: 80,  genre: 'Novel', stock: 0 },
  { title: 'Clean Code', price: 350, genre: 'Tech',  stock: 2 },
];
```

## 1. Mảng: viết gì → ra gì

| Cần | Code | Kết quả |
|---|---|---|
| Lấy 1 field mỗi phần tử | `books.map((b) => b.title)` | `['Mat Biec', 'Hoa Vang', 'Clean Code']` |
| Đổi dạng mỗi phần tử | `books.map((b) => ({ name: b.title, inStock: b.stock > 0 }))` | `[{ name: 'Mat Biec', inStock: true }, { name: 'Hoa Vang', inStock: false }, ...]` |
| Giữ phần tử thỏa điều kiện | `books.filter((b) => b.price <= 100)` | `[{Mat Biec}, {Hoa Vang}]` (không có → `[]`) |
| Phần tử đầu tiên khớp | `books.find((b) => b.genre === 'Tech')` | `{ title: 'Clean Code', ... }` (không có → `undefined`) |
| Vị trí phần tử khớp | `books.findIndex((b) => b.genre === 'Tech')` | `2` (không có → `-1`) |
| Có ít nhất 1 cái? | `books.some((b) => b.stock === 0)` | `true` |
| Tất cả đều? | `books.every((b) => b.price > 50)` | `true` (mảng rỗng luôn `true`) |
| Tổng | `books.reduce((sum, b) => sum + b.price, 0)` | `530` |
| Tổng giá trị tồn kho | `books.reduce((sum, b) => sum + b.price * b.stock, 0)` | `1200` (100·5 + 80·0 + 350·2) |
| Sắp xếp số giảm dần | `books.toSorted((a, b) => b.price - a.price)` | Clean Code, Mat Biec, Hoa Vang |
| Sắp xếp chuỗi A→Z | `books.toSorted((a, b) => a.title.localeCompare(b.title))` | Clean Code, Hoa Vang, Mat Biec |
| Nhóm | `Object.groupBy(books, (b) => b.genre)` | `{ Novel: [{Mat Biec}, {Hoa Vang}], Tech: [{Clean Code}] }` |
| Bỏ trùng | `[...new Set(books.map((b) => b.genre))]` | `['Novel', 'Tech']` |
| Làm phẳng | `[[1, 2], [3]].flat()` | `[1, 2, 3]` |
| Gom mảng con | `[{ tags: ['a', 'b'] }, { tags: ['b', 'c'] }].flatMap((x) => x.tags)` | `['a', 'b', 'b', 'c']` |
| Có chứa | `['a', 'b'].includes('b')` | `true` |
| Phần tử cuối | `books.at(-1).title` | `'Clean Code'` |

```js
// Đếm theo key
const count = books.reduce((acc, b) => { acc[b.genre] = (acc[b.genre] ?? 0) + 1; return acc; }, {});
// → { Novel: 2, Tech: 1 }

// Trung bình (an toàn khi mảng rỗng)
const avg = (xs) => (xs.length ? xs.reduce((a, b) => a + b, 0) / xs.length : 0);
avg([100, 80, 350]);   // → 176.66666666666666  (nhớ làm tròn, xem §4)
avg([]);               // → 0  (không có check thì ra NaN)
```

`sort()`, `reverse()`, `splice()` **làm thay đổi** mảng gốc. Nên dùng `toSorted()`, `toReversed()`, `slice()`.
`[10, 9, 1].sort()` → `[1, 10, 9]` (sắp như chuỗi!). Đúng: `[10, 9, 1].toSorted((a, b) => a - b)` → `[1, 9, 10]`.

## 2. Object

```js
const book = { title: 'Mat Biec', author: { name: 'NNA' } };

const { title, price = 0, author: { name } = {} } = book;
// → title = 'Mat Biec', price = 0 (không có nên lấy mặc định), name = 'NNA'

const { _id, __v, ...rest } = { _id: 'b1', __v: 0, title: 'X', price: 1 };
// → rest = { title: 'X', price: 1 }        (bỏ bớt field; chỉ dùng với object thuần)

({ ...{ a: 1, b: 2 }, ...{ b: 3 }, c: 4 })  // → { a: 1, b: 3, c: 4 }   (key phía sau ghi đè)

Object.keys({ a: 1, b: 2 })                 // → ['a', 'b']
Object.entries({ a: 1, b: 2 })              // → [['a', 1], ['b', 2]]
Object.fromEntries(Object.entries({ a: 1, b: 2 }).map(([k, v]) => [k, v * 2]))  // → { a: 2, b: 4 }

book?.publisher?.name ?? 'N/A'              // → 'N/A'   (không lỗi dù publisher không có)
```

| Biểu thức | `??` | `\|\|` |
|---|---|---|
| `0 ?? 10` / `0 \|\| 10` | `0` | `10` |
| `'' ?? 'x'` / `'' \|\| 'x'` | `''` | `'x'` |
| `null ?? 10` / `null \|\| 10` | `10` | `10` |

`??` chỉ thay khi `null`/`undefined`. Với số (giá, số lượng có thể = 0) luôn dùng `??`.

## 3. Document Mongoose trong JS

```js
const doc = await Book.findById(id);
if (!doc) return res.status(404).json({ error: 'Not found' });
const obj = doc.toObject();                   // chuyển sang object thuần trước khi spread/xóa field
res.json({ ...obj, priceWithTax: obj.price * 1.1 });

const list = await Book.find().lean();        // lấy thẳng object thuần (khi chỉ đọc)

// So sánh ObjectId: không bao giờ dùng ===
doc.author.equals(otherId);                   // true/false
String(doc.author) === String(otherId);       // cũng được
ids.some((x) => x.equals(sid));               // mảng có chứa id không
```

Vòng lặp async:

```js
// Song song: các query độc lập với nhau
const results = await Promise.all(ids.map((id) => Book.findById(id)));   // → [doc, doc, null, ...] đúng thứ tự ids

// Tuần tự: khi cần đúng thứ tự thực hiện
for (const id of ids) { await Book.updateOne({ _id: id }, { $inc: { views: 1 } }); }

// SAI: forEach không chờ → response gửi đi trước khi các lệnh xong
ids.forEach(async (id) => { await Book.findById(id); });
```

## 4. Format output (làm ở bước cuối, ngay trước `res.json`)

### Số

| Code | Kết quả | Kiểu |
|---|---|---|
| `(3.14159).toFixed(2)` | `"3.14"` | chuỗi |
| `(90).toFixed(1)` | `"90.0"` | chuỗi |
| `Math.round(3.14159 * 100) / 100` | `3.14` | số |
| `Number((176.666).toFixed(2))` | `176.67` | số |
| `(1234567.891).toLocaleString('vi-VN', { maximumFractionDigits: 2 })` | `"1.234.567,89"` | chuỗi |
| `(1234567.891).toLocaleString('en-US', { maximumFractionDigits: 2 })` | `"1,234,567.89"` | chuỗi |
| `String(7).padStart(3, '0')` | `"007"` | chuỗi |
| `0.1 + 0.2` | `0.30000000000000004` | số → phải làm tròn |
| `(1.005).toFixed(2)` | `"1.00"` (không phải 1.01: lỗi số thực, chấp nhận) | chuỗi |

### Tiền / phần trăm

| Code | Kết quả |
|---|---|
| `(1500000).toLocaleString('vi-VN', { style: 'currency', currency: 'VND' })` | `"1.500.000 ₫"` |
| `(1500.5).toLocaleString('en-US', { style: 'currency', currency: 'USD' })` | `"$1,500.50"` |
| `(0.1256).toLocaleString('en-US', { style: 'percent', maximumFractionDigits: 1 })` | `"12.6%"` (đầu vào là tỉ lệ 0-1) |
| `` `${(1 / 3 * 100).toFixed(2)}%` `` | `"33.33%"` (đầu vào đã nhân 100) |

### Đề ghi `90.0` / `85.50` (số, không có nháy)

`JSON.stringify` bỏ số 0 ở đuôi: `90.0` → `90`. Muốn giữ:

```js
JSON.stringify({ a: 90.0 })                                   // → {"a":90}        mất .0
JSON.stringify({ a: (90).toFixed(1) })                        // → {"a":"90.0"}    thành chuỗi (có nháy)
JSON.stringify({ a: JSON.rawJSON((90).toFixed(1)) })          // → {"a":90.0}      ĐÚNG: số, giữ .0
JSON.stringify({ a: JSON.rawJSON((85.5).toFixed(2)) })        // → {"a":85.50}

// Trong route: res.json dùng được luôn
res.json(rows.map((r) => ({ ...r, avgScore: JSON.rawJSON(Number(r.avgScore ?? 0).toFixed(1)) })));
```

Đề chấp nhận chuỗi thì chỉ cần `toFixed`. Sau `JSON.rawJSON` giá trị không còn là number: đừng tính tiếp.

### Chuỗi

| Code | Kết quả |
|---|---|
| `'  Mat Biec  '.trim()` | `"Mat Biec"` |
| `'nGUYEN'.charAt(0).toUpperCase() + 'nGUYEN'.slice(1).toLowerCase()` | `"Nguyen"` |
| `'nguyen van an'.split(' ').map((w) => w[0].toUpperCase() + w.slice(1)).join(' ')` | `"Nguyen Van An"` |
| `'a,b, c'.split(',').map((s) => s.trim())` | `["a", "b", "c"]` |
| `'2024-05-01'.replaceAll('-', '/')` | `"2024/05/01"` |
| `` `${b.title} (${b.price})` `` | `"Mat Biec (100)"` |

### Ngày giờ

Với `const d = new Date('2024-07-18T09:30:00Z')`:

| Code | Kết quả |
|---|---|
| `d.toISOString()` | `"2024-07-18T09:30:00.000Z"` (`res.json` gửi Date dạng này) |
| `d.toISOString().slice(0, 10)` | `"2024-07-18"` (ngày theo UTC) |
| `d.toLocaleDateString('vi-VN', { day: '2-digit', month: '2-digit', year: 'numeric', timeZone: 'Asia/Ho_Chi_Minh' })` | `"18/07/2024"` |
| `d.toLocaleString('vi-VN', { timeZone: 'Asia/Ho_Chi_Minh' })` | `"16:30:00 18/7/2024"` (giờ VN = UTC+7) |
| `d.getUTCFullYear()` / `d.getUTCMonth()` / `d.getUTCDate()` | `2024` / `6` (**0-11**, phải +1) / `18` |
| `d.getUTCDay()` | `4` (0 = Chủ nhật ... 4 = thứ Năm) |
| dd/mm/yyyy tự ghép: `` `${String(d.getUTCDate()).padStart(2, '0')}/${String(d.getUTCMonth() + 1).padStart(2, '0')}/${d.getUTCFullYear()}` `` | `"18/07/2024"` |
| `(new Date('2024-07-18') - new Date('2024-07-01')) / 86_400_000` | `17` (số ngày chênh lệch) |
| `new Date(new Date('2024-07-30').getTime() + 3 * 86_400_000)` | `2024-08-02T00:00:00.000Z` (cộng 3 ngày) |

Tạo Date từ chuỗi:

| Code | Thành |
|---|---|
| `new Date('2024-07-18')` | `2024-07-18T00:00:00.000Z` (chỉ có ngày = 0h UTC) |
| `new Date('2024-07-18T09:30:00')` | **giờ địa phương** (ở VN → `02:30Z`) |
| `new Date('2024-07-18T09:30:00Z')` | `09:30Z` (UTC rõ ràng) |
| `new Date(2024, 6, 18)` | tháng tính từ 0 (6 = tháng 7), giờ địa phương |
| `new Date('bad')` | `Invalid Date` (`isNaN(d)` → `true`) |
| `new Date('2024-02-30')` | `2024-03-01` (**không báo lỗi**, tự nhảy ngày!) → xem `isDateStr` ở §5 |

MongoDB lưu kiểu BSON `Date` (UTC). Lọc bằng object `Date`, không dùng chuỗi: xem [03-Query](03-Query.md) §1.

### Ví dụ trọn vẹn: kết quả query → đúng format đề

```js
// rows từ query/aggregate:
// [ { _id: 'b1', title: 'mat biec', price: 1500000, avgRating: 4.666666, publishedAt: Date(2024-07-18T00:00:00Z) } ]
res.json(rows.map((r) => ({
  id: r._id,
  title: r.title.charAt(0).toUpperCase() + r.title.slice(1),
  price: r.price.toLocaleString('vi-VN', { style: 'currency', currency: 'VND' }),
  avgRating: JSON.rawJSON((r.avgRating ?? 0).toFixed(1)),
  publishedAt: r.publishedAt.toISOString().slice(0, 10),
})));
// → [{"id":"b1","title":"Mat biec","price":"1.500.000 ₫","avgRating":4.7,"publishedAt":"2024-07-18"}]
```

## 5. Validate input (trước khi query)

### Ép kiểu: input từ `req.query` / `req.params` luôn là chuỗi

| Code | Kết quả | Ghi chú |
|---|---|---|
| `Number('12.5')` | `12.5` | |
| `Number('')` / `Number('  ')` | `0` | **bẫy**: rỗng thành 0 → check rỗng trước |
| `Number(null)` | `0` | **bẫy** |
| `Number(undefined)` | `NaN` | |
| `Number('abc')` / `Number('12px')` | `NaN` | |
| `Number('1e3')` | `1000` | |
| `parseInt('12px', 10)` | `12` | đọc tới khi gặp ký tự lạ |
| `parseInt('abc', 10)` | `NaN` | |
| `parseFloat('12.5kg')` | `12.5` | |
| `Number.isFinite(NaN)` / `Number.isFinite('5')` | `false` / `false` | không tự ép chuỗi |
| `Number.isInteger(5.0)` / `Number.isInteger(5.5)` | `true` / `false` | |
| `req.query.active === 'true'` | `true` / `false` | boolean trong query là chuỗi |

### Hàm kiểm tra (copy dùng luôn)

```js
const isBlank = (v) => v === undefined || v === null || String(v).trim() === '';
const isNum = (v) => !isBlank(v) && Number.isFinite(Number(v));
const isInt = (v) => !isBlank(v) && Number.isInteger(Number(v));
const isEmail = (v) => typeof v === 'string' && /^\S+@\S+\.\S+$/.test(v);
const isPhone = (v) => /^0\d{9}$/.test(String(v));                    // 10 số, bắt đầu bằng 0
const isDateStr = (s) => /^\d{4}-\d{2}-\d{2}$/.test(s) && !isNaN(new Date(s))
  && new Date(s).toISOString().slice(0, 10) === s;                    // chặn cả 2024-02-30
```

| Hàm | Đúng (`true`) | Sai (`false`) |
|---|---|---|
| `isBlank` | `undefined`, `null`, `''`, `'  '` | `'a'`, `0`, `false` |
| `isNum` | `12`, `'12.5'`, `'0'`, `-3` | `''`, `' '`, `'abc'`, `'12px'`, `null` |
| `isInt` | `5`, `'5'`, `'5.0'` | `'5.5'`, `''`, `null` |
| `isEmail` | `'a@b.co'` | `'abc'`, `'a@b'`, `'a b@c.d'`, `123` |
| `isPhone` | `'0912345678'` | `'912345678'`, `'09123'`, `'+84912345678'` |
| `isDateStr` | `'2024-07-18'`, `'2024-02-29'` | `'2023-02-29'`, `'2024-02-30'`, `'2024-13-01'`, `'18/07/2024'`, `'2024-7-1'` |

### Gom lỗi theo field, trả 400 một lần

```js
app.post('/books', async (req, res) => {
  const { title, price, quantity, status, email, publishedAt } = req.body ?? {};
  const errors = {};
  if (isBlank(title)) errors.title = 'Title is required';
  else if (String(title).trim().length < 3) errors.title = 'Title must be at least 3 characters';
  if (isBlank(price)) errors.price = 'Price is required';
  else if (!isNum(price) || Number(price) < 0) errors.price = 'Price must be a number >= 0';
  if (quantity !== undefined && (!isInt(quantity) || Number(quantity) < 1)) errors.quantity = 'Quantity must be an integer >= 1';
  if (status !== undefined && !['AVAILABLE', 'SOLD'].includes(status)) errors.status = 'Status must be AVAILABLE or SOLD';
  if (email !== undefined && !isEmail(email)) errors.email = 'Invalid email';
  if (publishedAt !== undefined && !isDateStr(publishedAt)) errors.publishedAt = 'publishedAt must be YYYY-MM-DD';
  if (Object.keys(errors).length) return res.status(400).json({ errors });

  const book = await Book.create({ title: title.trim(), price: Number(price), quantity, status, email, publishedAt });
  res.status(201).json(book);
});
```

| Body gửi lên | Response |
|---|---|
| (không có body) | `400 { errors: { title: 'Title is required', price: 'Price is required' } }` |
| `{ title: 'Mat Biec', price: 100 }` | `201` + book |
| `{ title: 'Clean Code', price: '0', quantity: '2' }` | `201` (chuỗi số vẫn hợp lệ) |
| `{ title: ' ab ', price: 'abc', quantity: 1.5, status: 'LOST', email: 'x', publishedAt: '2024-02-30' }` | `400 { errors: { title: '...at least 3 characters', price: '...number >= 0', quantity: '...integer >= 1', status: '...AVAILABLE or SOLD', email: 'Invalid email', publishedAt: '...YYYY-MM-DD' } }` |

Id trên path: `mongoose.isValidObjectId(id)`:
`'6aed1f2c3b4a5d6e7f8a9b0c'` → `true`; `'abc'` → `false`; `'123456789012'` → `false` (Mongoose 9).

### Hoặc để schema Mongoose validate, rồi format lỗi

Schema (xem [02-Model](02-Model.md)):

```js
title:  { type: String, required: [true, 'Title is required'], trim: true, minlength: [3, 'Title must be at least 3 characters'] },
price:  { type: Number, required: true, min: [0, 'Price must be >= 0'] },
status: { type: String, enum: { values: ['AVAILABLE', 'SOLD'], message: '{VALUE} is not a valid status' } },
email:  { type: String, match: [/^\S+@\S+\.\S+$/, 'Invalid email'] },
```

`Book.create({ title: ' ab ', price: -5, status: 'LOST', email: 'abc' })` ném `err` với:

```js
err.name     // 'ValidationError'
err.message  // 'Book validation failed: title: Title must be at least 3 characters, price: Price must be >= 0, status: LOST is not a valid status, email: Invalid email'
err.errors   // { title: ValidatorError, price: ValidatorError, status: ..., email: ... }
err.errors.price.message  // 'Price must be >= 0'
err.errors.price.kind     // 'min'   (các kind khác: 'required', 'minlength', 'enum', 'regexp')
```

| Không truyền `message` riêng | Message mặc định |
|---|---|
| `required: true` | `` Path `price` is required. `` |
| `type: Number` nhận `'abc'` | `Cast to Number failed for value "abc" (type string) at path "price" for model "Book"` |
| `type: Date` nhận `'bad'` | `Cast to date failed for value "bad" (type string) at path "publishedAt" ...` |

Chuyển `err.errors` thành dạng `{ field: message }` trong error handler ([01-Express](01-Express.md) §1):

```js
if (err.name === 'ValidationError') {
  const errors = Object.fromEntries(Object.entries(err.errors).map(([field, e]) => [field, e.message]));
  return res.status(400).json({ errors });
  // → { "errors": { "title": "Title must be at least 3 characters", "price": "Price must be >= 0", ... } }
}
// Đề muốn mảng thông báo:  Object.values(err.errors).map((e) => e.message)
// → ["Title must be at least 3 characters", "Price must be >= 0", ...]
```

`price: '100'` (chuỗi số) vẫn hợp lệ: Mongoose tự ép thành `100`; `title: '  Mat Biec '` được `trim` thành `'Mat Biec'`.

## Bẫy thường gặp

- `toFixed` / `toLocaleString` trả về **chuỗi**: đừng cộng trừ tiếp. Cần số thì `Number(x.toFixed(2))`.
- `$round` / `Math.round` đều cho `90` chứ không phải `90.0`: dùng `JSON.rawJSON(x.toFixed(1))`, gọi ở bước map cuối.
- `Number('')` và `Number(null)` là `0`, không phải `NaN`: check rỗng trước khi ép số.
- `new Date('2024-02-30')` không lỗi mà thành 01/03: dùng `isDateStr`.
- `getMonth()` / `getUTCMonth()` trả 0-11 → `+ 1` khi hiển thị.
- Spread document Mongoose (`{ ...doc }`) sẽ copy cả phần nội bộ: gọi `.toObject()` trước hoặc dùng `.lean()`.
- Validator schema không chạy khi `findByIdAndUpdate` nếu thiếu `runValidators: true`.
