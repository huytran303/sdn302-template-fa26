# 05 · Xử lý dữ liệu bằng JavaScript: mảng, object, async, format

Dùng để **biến đổi** dữ liệu sau khi query. Lọc/sắp xếp/nhóm tập dữ liệu lớn thì làm trong query hoặc aggregate.

## Tra nhanh

| Cần | Dùng | Trả về |
|---|---|---|
| Biến đổi từng phần tử | `arr.map(fn)` | mảng mới, cùng độ dài |
| Giữ phần tử thỏa điều kiện | `arr.filter(fn)` | mảng mới |
| Phần tử đầu tiên khớp | `arr.find(fn)` / `arr.findIndex(fn)` | phần tử hoặc `undefined` / vị trí hoặc `-1` |
| Có ít nhất 1 / tất cả | `arr.some(fn)` / `arr.every(fn)` | boolean (`every` trên `[]` là `true`) |
| Gộp về 1 giá trị | `arr.reduce(fn, init)` | bất kỳ (luôn truyền `init`) |
| Sắp xếp không đổi mảng gốc | `arr.toSorted((a, b) => a.x - b.x)` | mảng mới |
| Bỏ trùng | `[...new Set(arr)]` | mảng mới |
| Làm phẳng | `arr.flat()` / `arr.flatMap(fn)` | mảng mới |
| Nhóm | `Object.groupBy(arr, (x) => x.key)` | `{ key: [items] }` (Node >= 21) |
| Có chứa | `arr.includes(v)` | boolean |
| Phần tử cuối | `arr.at(-1)` | phần tử |

## 1. Công thức với mảng

```js
const books = [
  { title: 'A', price: 100, genre: 'edu' },
  { title: 'B', price: 20, genre: 'edu' },
  { title: 'C', price: 500, genre: 'tech' },
];

books.map((b) => b.title);                              // ['A', 'B', 'C']
books.filter((b) => b.price < 100);                     // [B]
books.reduce((sum, b) => sum + b.price, 0);             // 620
books.toSorted((a, b) => b.price - a.price);            // giá giảm dần
books.toSorted((a, b) => a.title.localeCompare(b.title)); // A→Z (chuỗi)
Object.groupBy(books, (b) => b.genre);                  // { edu: [A, B], tech: [C] }

// Đếm theo key (object không prototype: an toàn với mọi key, kể cả "constructor")
const count = books.reduce((acc, b) => { acc[b.genre] = (acc[b.genre] ?? 0) + 1; return acc; }, Object.create(null));

// Trung bình (an toàn khi mảng rỗng)
const avg = (xs) => (xs.length ? xs.reduce((a, b) => a + b, 0) / xs.length : 0);
```

`sort()`, `reverse()`, `splice()` **làm thay đổi** mảng gốc. Nên dùng `toSorted()`, `toReversed()`, `slice()`.

## 2. Object

```js
const { title, price = 0, author: { name } = {} } = book;  // destructuring + mặc định + lồng nhau
const { _id, __v, ...rest } = plainObj;                     // bỏ bớt field (chỉ với object thuần)
const merged = { ...a, ...b, price: 200 };                  // key phía sau ghi đè
Object.keys(o); Object.values(o); Object.entries(o);
Object.fromEntries(Object.entries(o).map(([k, v]) => [k, v * 2]));
o?.a?.b ?? 'N/A';                                           // truy cập an toàn + mặc định
```

`??` chỉ thay khi `null`/`undefined`; `||` thay cả `0`, `''`, `false`. Với số thì dùng `??`.

## 3. Document Mongoose trong JS

```js
const doc = await Book.findById(id);
if (!doc) return res.status(404).json({ error: 'Not found' });
const obj = doc.toObject();                   // chuyển sang object thuần trước khi spread/xóa field
res.json({ ...obj, priceWithTax: obj.price * 1.1 });

const list = await Book.find().lean();        // lấy thẳng object thuần (khi chỉ đọc)

// So sánh ObjectId: không bao giờ dùng ===
doc.author.equals(otherId);                   // true/false
String(doc.author) === String(otherId);       // cũng được
ids.some((x) => x.equals(sid));               // mảng có chứa id không
```

## 4. Vòng lặp async

```js
// Song song: các query độc lập với nhau
const results = await Promise.all(ids.map((id) => Book.findById(id)));

// Tuần tự: khi cần đúng thứ tự
for (const id of ids) { await Book.updateOne({ _id: id }, { $inc: { views: 1 } }); }

// SAI: forEach không chờ
ids.forEach(async (id) => { await Book.findById(id); });   // response gửi đi trước khi các lệnh này xong
```

## 5. Format (chỉ làm ở bước cuối, ngay trước `res.json`)

```js
// Số
(3.14159).toFixed(2);                                          // "3.14" (chuỗi)
Math.round(3.14159 * 100) / 100;                               // 3.14 (số: trong JSON nên giữ số là số)
(1234567.891).toLocaleString('vi-VN', { maximumFractionDigits: 2 });  // "1.234.567,89"
(1234567.891).toLocaleString('en-US', { maximumFractionDigits: 2 });  // "1,234,567.89"

// Đề ghi 90.0 / 85.50 (giữ số 0 ở đuôi). Mặc định JSON.stringify(90.0) → 90 (mất .0)
// Cần KIỂU SỐ mà vẫn hiện 90.0 → JSON.rawJSON (Node ≥ 21), res.json dùng được luôn
avgScore: JSON.rawJSON(Number(r.avgScore ?? 0).toFixed(1))     // → "avgScore": 90.0  (số, không nháy)
price:    JSON.rawJSON((85.5).toFixed(2))                      // → "price": 85.50
// Chấp nhận chuỗi → toFixed là đủ
(90).toFixed(1);                                               // "90.0" (chuỗi, có nháy)

// Tiền / phần trăm
(1500000).toLocaleString('vi-VN', { style: 'currency', currency: 'VND' }); // "1.500.000 ₫"
(1500.5).toLocaleString('en-US', { style: 'currency', currency: 'USD' });  // "$1,500.50"
(0.1256).toLocaleString('en-US', { style: 'percent', maximumFractionDigits: 1 }); // "12.6%"

// Ép kiểu an toàn
Number('12.5');           // 12.5;   Number('') → 0 (!), Number('abc') → NaN
parseInt('12px', 10);     // 12
Number.isFinite(n);       // false với NaN / Infinity

// Chuỗi
s.trim(); s.toUpperCase(); s.padStart(2, '0'); s.replaceAll(',', '-'); s.split(',');
s.charAt(0).toUpperCase() + s.slice(1).toLowerCase();    // viết hoa chữ đầu
```

### Ngày giờ

```js
new Date('2024-07-18');                 // chuỗi chỉ có ngày = 0h UTC
new Date('2024-07-18T09:30:00');        // không có Z = giờ ĐỊA PHƯƠNG (UTC+7 ở VN → 02:30Z)
new Date('2024-07-18T09:30:00Z');       // UTC rõ ràng
new Date(2024, 6, 18);                  // tháng tính từ 0 (6 = tháng 7), giờ địa phương

d.toISOString();                        // "2024-07-18T00:00:00.000Z" (res.json gửi dạng này)
d.toLocaleDateString('vi-VN', { day: '2-digit', month: '2-digit', year: 'numeric', timeZone: 'Asia/Ho_Chi_Minh' }); // "18/07/2024"
d.toISOString().slice(0, 10);           // "2024-07-18" (ngày theo UTC)
isNaN(new Date('bad'));                 // true → ngày không hợp lệ

const days = (b - a) / 86_400_000;      // chênh lệch số ngày
```

MongoDB lưu kiểu BSON `Date` (UTC). Lọc bằng object `Date`, không dùng chuỗi: xem [03-Query](03-Query.md) §1.

## Bẫy thường gặp

- `toFixed` / `toLocaleString` trả về **chuỗi**: đừng cộng trừ tiếp.
- Output mẫu có `90.0` (không có dấu nháy): `$round` và `Math.round` đều cho `90`. Dùng `JSON.rawJSON(x.toFixed(1))` để ra số `90.0`. Gọi nó ở bước map cuối cùng, ngay trước `res.json`: kết quả không còn là number để tính toán tiếp.
- `getMonth()` trả 0-11 → `+ 1` khi hiển thị.
- Spread document Mongoose (`{ ...doc }`) sẽ copy cả phần nội bộ: gọi `.toObject()` trước hoặc dùng `.lean()`.
- `arr.sort()` không truyền hàm so sánh sẽ sắp số như chuỗi: `[10, 9, 1].sort()` → `[1, 10, 9]`.
